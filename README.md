# Omahub Capture

The screenshot thumbnail now ships inside [Omahub](https://github.com/elberacasa/omahub), and this repository is archived.

Install Omahub, open it with SUPER + A, and turn on Screenshot thumbnail in the Capture section:

```bash
omarchy plugin add https://github.com/elberacasa/omahub.git --enable
omarchy restart shell
```

The history of the thumbnail continues in Omahub's `capture/` folder.
